# SPEC 草稿：補全素（不吃五辛）吃得到的蛋白質菜

> 狀態：**草稿，尚未動工**。2026-09-18 交接整理時寫下，等 Yolin 決定要不要做（見 `STATUS.md`「等 Yolin 回覆」）。

## 為什麼

v0.33.0 加了「素食成員每餐排一道蛋、豆製品或奶類的菜」（家人頁開關，預設開）。實測（三種家庭 × 8 組種子 × 連排 3 週）：

| 家庭 | 開關關 | 開關開 |
|---|---|---|
| 有蛋奶素成員 | 25% 的午晚餐沒有 | 0% |
| 有全素成員 | 43% | **9%** |
| 全家全素 | 32% | **5%** |

全素（不吃蛋奶、不吃五辛）還剩 5–9%，原因是池子小：2026-09-18 盤點，全素不吃五辛吃得到、而且算得上「豆製品的菜」的只有
主菜 14、配菜 5、湯 5，共 24 道（其中配菜的「涼拌四季豆」「蒜炒豌豆莢」其實是誤判，見 STATUS 等 Yolin 第 1 項，扣掉後只剩 22 道）。
再加上「主菜 14 天不重複」與「同一樣主角食材三天內不要太常出現」，有些餐真的沒得挑。

## 要做的事

1. 新增 8–10 道**全素、不含五辛（或五辛可省略 `alliumOptional`）**、主角是豆製品的菜，優先補**配菜與湯**（主菜已有 14 道，配菜與湯各只有約 5 道）。
   主角要分散在不同豆製品，才不會被「同一樣主角三天內不要太常出現」擋掉：板豆腐、嫩豆腐、豆干、豆皮、百頁豆腐、麵腸、毛豆、油豆腐、黃豆。
   候選（需逐道查食藥署編號，`npm run findfood -- 詞`）：毛豆炒玉米、滷百頁豆腐、麵腸炒青椒、豆皮炒青江菜、毛豆豆腐羹、海帶豆腐湯、黃豆芽豆皮湯、涼拌豆干絲、紅燒麵腸、枸杞豆腐湯。
2. 每道照 `data/recipes/*.json` 的格式寫，`npm run build-recipes` 驗證；步驟與名稱守健康紅線禁用詞（`copytest`）。
3. `recipetest` 的數量門檻跟著墊高；`plannertest` 裡「全家全素：開關開著 ≤ 10%」「有全素 ≤ 20%」的門檻，補完後照實測重設、留餘裕。

## 驗收

· 全家全素、有全素成員兩種家庭，素食成員沒有蛋豆奶菜的午晚餐 ≤ 3%（照實測再定）。
· 「同一樣主角食材三天內 ≥ 4 次」仍然是 0；素食成員每餐 ≥ 3 道；菜色種類不減少。
· 新斷言各自有突變驗紅。

## 不做的事

· 不把這條加分改成硬性規定（Yolin 已選「強加分、不硬擋」）。
· 不改「三天內不要太常出現」的優先順序（它先定，而且拿掉會回到豆干三天四道）。
